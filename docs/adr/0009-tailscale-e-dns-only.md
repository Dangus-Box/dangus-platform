# Acesso administrativo só via Tailscale, DNS da Cloudflare em modo DNS-only

O Host expõe publicamente apenas as portas 80 e 443. SSH, o Grafana e o painel admin do Unleash só são acessíveis pelo Tailscale. O GitHub Actions entra na rede do Tailscale como um nó temporário durante o deploy, e o console web da Hostinger é o acesso de emergência. Loki, Prometheus e os bancos nunca saem da rede Docker interna. Quando houver um Host Ops separado, o Tailscale também passa a ser a rede entre os Hosts, já que a Hostinger não oferece rede privada.

Os registros DNS ficam na Cloudflare em modo DNS-only (sem proxy), e o TLS é emitido pelo `kamal-proxy`. Conforme a [ADR-0015](0015-dominio-proprio-dns-only.md), cada Produto usa domínio próprio na sua zona, aceitando apex ou um nível de subdomínio. Para subdomínios, usamos nomes de um nível só (`api.produto.com`, `api-staging.produto.com`, `analytics.dangus-box.com`, `flags.dangus-box.com`), porque o certificado grátis da Cloudflare só cobre um nível de subdomínio. Assim, o proxy da Cloudflare pode ser ligado no futuro sem pagar pelo Advanced Certificate Manager.
